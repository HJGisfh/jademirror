## 常见问题

### Q: 玉灵童子不说话？
A: 检查"自动语音播报"设置是否开启，确认设备音量正常。

### Q: 语音识别不工作？
A: 检查麦克风权限，确认"自动监听"设置已开启。

### Q: 页面不跳转？
A: 检查"自动跳转到下一步"设置是否开启。

## 技术栈

- **前端**: Flutter + Provider
- **后端**: Python Flask
- **语音识别**: speech_to_text
- **语音合成**: flutter_tts
- **网络请求**: dio
